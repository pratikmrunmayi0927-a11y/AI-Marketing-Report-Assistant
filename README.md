# 📊 AI Marketing Report Assistant

## Features

-CSV Upload
-Data Cleaning
-KPI Dashboard
-Interactive Charts
-AI Insights (Groq)
-PDF Report
-Excel Report
-Report History
-SQLite Database
-Search & Filters

## Technologies

-Python
-Streamlit
-Pandas
-Plotly
-Groq API
-SQLite

## Run

'''bash
pip install -r requirements.txt
streamlit run app.py
'''
